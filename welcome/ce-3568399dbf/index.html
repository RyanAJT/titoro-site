If you downloaded "Everything in one zip", open it first. Inside are the 4 skill zips. Upload those 4 zips to Claude as they are: don't unzip them.

2. Turn on two settings in Claude

  1. Open claude.ai (paid plan: Pro or above) and go to Settings → Capabilities.
  2. Turn on Code execution and file creation (in newer layouts it's called Create and edit files). The reel-maker needs it to render video.
  3. Make sure web search is on in your chat (the tools button in the message box). The scout needs it.

3. Upload the 4 skills

  1. In Claude, go to Customize → Skills.
  2. Click + (or Add) → Upload a skill, and pick reel-scout.zip.
  3. Do the same for reel-writer.zip, reel-maker.zip and comment-to-dm.zip.
  4. Check all 4 are switched on.

4. Set up your voice (once)

Create a Claude Project called Content Engine and start a chat in it:

Set up my voice card for the Content Engine.

Claude asks about your business and for 3-5 captions you wrote. Save the voice card it gives you in the Project's instructions, so every chat sounds like you.

5. Your weekly routine

In the Content Engine Project, every week:

Run my weekly scout. Write the top 3 as reels. Render reel 1 in the data style. Set up the comment-to-DM for this reel.

Styles: paper (cream, tutorials), data (dark, numbers), neon (black and pink, hype), pop (yellow, bold tips). Want your voice on it? Record a voice memo of the script on your phone (or use ElevenLabs) and upload it with "use this voiceover". Without one you get a captions-and-music reel.

  • Claude doesn't use the skill: name it in your message, e.g. "use reel-maker to render this".

  • The video won't render: check step 2 is on. If your Claude still can't make the mp4, ask it to give you the reel.json and run the same command in Claude Code or on your computer (the skill explains how).
