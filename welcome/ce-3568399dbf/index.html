If something's off

Quick fixes.

Claude isn't using the skill

Name it in your message: "use reel-maker to render this". Check it's switched on in Customize → Skills.

The upload failed

Upload the 4 separate skill zips, not the kit zip, and don't unzip them first. Each zip has to contain its folder (for example reel-maker/SKILL.md).

The video won't render

Make sure step 01 is on. The 11 styles are drawn in a browser inside Claude's workspace, and a reel takes a few minutes. If your Claude says it can't run a browser, ask it to "use the classic renderer" for a simpler reel, or run reel-maker in Claude Code on your computer.

Can I use my brand colours?

Yes. Say "use my colours #hex for the accent and #hex for the background" and Claude changes them in the reel.
