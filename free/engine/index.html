Claude plans your month of posts. This file makes it learn.

Claude doesn't learn from your posts on its own. A plain chat never sees which post got watched. Wire up three things and it writes each new week from your own results. Example business: a barbershop.

PROMPT 1 · MONTH PLAN

Plan 30 days, add week one to Buffer

First connect Buffer: in Claude go to Settings → Connectors → Buffer → Connect and log in to Buffer. No API key needed.

Plan 30 days of posts for my barbershop, [SHOP NAME] in [CITY].
Mix these post types across the month:
- fresh fades and cuts (show the finished cut)
- before and after transformations
- chair talk (a client story or a barber tip)
- booking reminders (slots this week, how to book)
For each day give me: the post type, a hook for the first second,
the caption (under 60 words, in a friendly local tone),
3 hashtags, and a short shot list I can film in under 2 minutes.
Then use the Buffer connector to add only week one (days 1 to 7)
to my Buffer [INSTAGRAM / TIKTOK] channel as DRAFTS.
Do not schedule or publish anything.
Finish with a table of all 30 days: day, post type, hook.
COPY

You still film the cuts. Claude plans all 30 days and writes the captions; only week one goes into Buffer for you to review. Buffer's Free plan caps how many posts can sit scheduled at once (the free account we tested shows a limit of 10), so add one week at a time.

PROMPT 2 · PLAYBOOK

One Google Doc: the memory

This doc is what Claude learns from. Not the model. Make it once.

Create a Google Doc called "[SHOP NAME] Playbook" with this layout:

PLAYBOOK · [SHOP NAME]
Last updated: [date]

WORKS (do more of this)
- [post type] · [hook] · why it worked: [views / saves / watch time]

FLOPPED (stop doing this)
- [post type] · [hook] · why it flopped: [views / saves / watch time]

RULES FOR NEXT WEEK
- 3 short rules written from the lists above

Keep it plain text so it is easy to update every week.
WORKS
FLOPPED
COPY

Needs the Google Drive connector in Claude so it can create and edit the doc.

PROMPT 3 · MONDAY LOOP

Run one task, every Monday

Once a week, on Monday, open Claude and run this prompt:

Run my weekly review:
1. Use the Buffer connector to pull last week's sent posts for
   [CHANNEL] with their metrics (views, reach, saves, average
   watch time).
2. Rank them. Move the top 3 into WORKS and the bottom 3 into
   FLOPPED in my "[SHOP NAME] Playbook" Google Doc, each with
   one line on why. Update the RULES FOR NEXT WEEK.
3. Draft next week's 7 posts using only what the Playbook says
   works. Avoid anything in FLOPPED.
4. Add them to Buffer as DRAFTS. Do not publish.
5. Send me a 5-line summary of what changed.
COPY

Buffer's connector returns per-post metrics such as views, reach, saves and average watch time. Week one, Claude is guessing; by week four the drafts are written from your own results.

What we tested: one manual run that pulled real Buffer stats and updated the Playbook doc. Step 4 (adding drafts to Buffer) was not part of that run, so check your drafts after it.

Optional, something to try: on a paid Claude plan you could save this prompt as a weekly scheduled task. We have not tested the automatic trigger, so check the first few runs yourself.

Tools. Buffer (free plan works for step 1): join.buffer.com/jing (affiliate link). Claude with the Buffer and Google Drive connectors. These prompts ask Claude for drafts only, so you check and schedule each post yourself.
