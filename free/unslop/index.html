How to make your vibe-coded app stop looking AI-made (unslop)

What you'll get
  • The install command for Claude Code
  • The exact /unslop commands to run
  • 4 prompts to steer the redesign
CommentUNSLOP

Most apps built with AI end up with the same look: purple-to-pink gradients, emoji used as icons, glowing buttons and the same three rounded cards. People have seen it hundreds of times, and it makes a product look rushed.

Unslop is a free, open-source skill for Claude Code by heydamir. You point it at a screen and it does three things:

  1. Audits it. It lists the signs of "slop" and where each one appears.
  2. Proposes a direction. Before editing anything, it suggests a design direction based on your product.
  3. Fixes it in passes: spacing, colour, icons, copy, type, layout, details, visuals and motion.

It can also make a short square video of the before and after for you to post.

Step 1: Install it in Claude Code

Open your terminal and run:

claude plugin install unslop --marketplace heydamir/unslop

On older versions of Claude Code, run these two lines instead:

claude plugin marketplace add heydamir/unslop
claude plugin install unslop@heydamir

Then start a new Claude Code session, or type /reload-plugins.

  • Just one project: run the install from the project's folder and add --scope local.
  • Whole team: after adding the marketplace, run claude plugin install unslop@heydamir --scope project and commit .claude/settings.json.

Step 2 (optional): Let it see live sites

To redesign a live website or make the before-and-after video, it needs Playwright. In your project folder run:

npm install -D playwright
npx playwright install chromium

The video also needs ffmpeg installed on your computer.

Step 3: Run it

Inside Claude Code, type one of these:

/unslop this dashboard
/unslop the hero of https://yoursite.com
/unslop my landing page and make the story video so I can post it

If another skill already uses the name, type /unslop:unslop instead. You can also just describe what you want in plain words.

4 prompts to steer the redesign

Add these after the command to get a result that fits your business:

  1. Pick the direction yourself: Before you change anything, give me 3 design directions for a [your business] aimed at [your customers]. Wait for me to pick one.
  2. Keep your brand: Keep my logo and my brand colour [#hex]. Remove everything else that looks AI-made.
  3. Fix the worst first: List every AI tell you found, ranked by how much it hurts trust. Fix only the top 5 and show me.
  4. Write like a person: Rewrite the headline and buttons in plain words a customer would say. No "supercharge", "seamless" or "unlock".

Good to know

  • It's free and open source. It can also add images through an image service, and it asks before each paid generation.
  • It works in Codex and Google Antigravity too. The install steps for those are on the GitHub page.
  • Check the result on your phone before you ship. A redesign can move buttons your customers already know.
